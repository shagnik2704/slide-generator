## 🎯 Recommendations

### To Match 3C's Style Even More Closely:

1. **Shorten Sentences Further**
   - Target: 5-10 words per sentence (currently ~10-15)
   - More repetition for emphasis
   - More parallel structure

2. **Add Explicit Reflection Pauses**
   - After rhetorical questions, add: "Pause and think about it."
   - Add: "Think about why this worked better."

3. **More Specific Visual Cues**
   - Use: "Screen recording showing..." vs. just "Screenshot"
   - Use: "Close-up: user typing..." for typing actions
   - Specify exact UI elements when relevant

4. **Emphasize Action/Doing**
   - "Let's open an AI tool"
   - "Type a vague prompt in the message box and submit it"
   - More "doing" language vs. "showing" language

5. **Rhythmic Repetition**
   - Use more parallel sentence structures
   - Example: "A weak prompt gets a weak answer. A strong prompt gets a smart answer."
