## Code Formatting Standards

### 1. Import Organization

```python
# Standard library imports (alphabetically sorted)
import json
import os
from pathlib import Path
from typing import Optional, List

# Third-party imports (alphabetically sorted)
from fastapi import APIRouter, HTTPException, Depends
from pydantic import BaseModel

# Local application imports (grouped by layer)
from src.api.auth import get_current_user, TokenData
from src.api.exceptions import ValidationError
from src.services.compliance_service import check_compliance
```

### 2. File Structure Template

```python
"""
Module docstring describing the purpose of this module.
"""
# ============================================================================
# IMPORTS
# ============================================================================
import logging
from typing import Optional

from fastapi import APIRouter, Depends

from src.api.auth import get_current_user, TokenData

# ============================================================================
# CONSTANTS
# ============================================================================
logger = logging.getLogger(__name__)
router = APIRouter(tags=["example"])

# ============================================================================
# MODELS
# ============================================================================
class MyRequest(BaseModel):
    """Request model."""
    field: str

# ============================================================================
# ROUTES
# ============================================================================
@router.post("/endpoint")
async def my_endpoint(
    request: MyRequest,
    current_user: TokenData = Depends(get_current_user)
):
    """Endpoint description."""
    pass

# ============================================================================
# HELPER FUNCTIONS
# ============================================================================
def helper_function():
    """Helper function description."""
    pass
```

### 3. Docstring Format

```python
def my_function(param1: str, param2: int) -> bool:
    """Brief description of the function.

    Args:
        param1: Description of param1
        param2: Description of param2

    Returns:
        Description of return value

    Raises:
        ValidationError: When validation fails
    """
    pass
```

### 4. Error Handling Pattern

```python
try:
    result = process_data(data)
    return {"status": "success", "data": result}
except ValueError as e:
    raise HTTPException(status_code=400, detail=str(e))
except FileNotFoundError:
    raise HTTPException(status_code=404, detail="Resource not found")
except Exception as e:
    logger.error(f"Unexpected error: {e}", exc_info=True)
    raise HTTPException(status_code=500, detail="Internal server error")
```

## Naming Conventions

| Category | Convention | Example |
|:---------|:-----------|:--------|
| Files | `snake_case.py` | `voice_service.py` |
| Classes | `PascalCase` | `AgentState` |
| Functions/Variables | `snake_case` | `generate_voice` |
| Constants | `UPPER_SNAKE_CASE` | `SEMAPHORE_CONFIG` |
| Private | `_leading_underscore` | `_extract_single` |
| Route modules | `snake_case.py` | `slides_translation.py` |
| Service modules | `*_service.py` | `compliance_service.py` |
| Node modules | `*_node.py` | `metadata_node.py` |
| React hooks | `use*.js` | `useChatArea.js` |
| Outline chat | `outline_chat_*.py` | `outline_chat_validation.py` |

## Best Practices

1. **Separation of concerns** — Routes are thin, delegate to services
2. **Dependency injection** — Use FastAPI's `Depends` for auth and shared deps
3. **Type hints** — Always use type hints for function parameters and returns
4. **Error handling** — Use `HTTPException` with specific status codes
5. **Logging** — Use structured logging with appropriate levels
6. **Validation** — Validate at the API boundary via Pydantic models
7. **Async** — Use `async def` for I/O-bound routes; run sync LLM calls in `run_in_executor`
8. **Semaphores** — Use `asyncio.Semaphore` for rate-limited concurrent operations (see `VC_utils.SEMAPHORE_CONFIG`)
9. **Lazy init** — Initialize LLM clients and external services lazily to avoid import-time errors
